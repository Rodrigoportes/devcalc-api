# DevCalc API 🧮

## Objetivo do Projeto

A DevCalc API é uma aplicação REST simples desenvolvida em **Java** com o framework **Javalin**. O principal objetivo é servir como uma base para a validação e implementação de **Pipelines de CI/CD** (Integração e Entrega Contínua) utilizando **GitHub Actions**. Ela fornece operações matemáticas básicas.

## Ferramenta de Build

O projeto utiliza o **Apache Maven** para gerenciamento de dependências, compilação e empacotamento.

## Como Executar Localmente

Para rodar a aplicação na sua máquina, você precisa ter o **Java Development Kit (JDK) versão 17 ou superior** e o **Maven** instalados.

### 1. Compilar o Projeto

Execute o comando Maven para baixar as dependências e compilar o código:

```bash
mvn clean install
